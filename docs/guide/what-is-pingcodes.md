# 什么是 PingCodes 拼车

PingCodes 是一个 **AI 订阅拼车平台**——把 Claude、OpenAI、Gemini 等官方 AI 订阅，按 **3 人、4 人** 的方式拼着用，价格大家平摊。

简单说：**一个官方真号的钱，几个人分着出，每人只花一小部分。**

## 拼车，而不是中转

市面上很多服务叫"中转站"——本质是二道贩子转发请求，你不知道背后是不是套壳、数据会不会被留存。PingCodes 走的是**拼车**模式：

| | 普通中转站 | PingCodes 拼车 |
| --- | --- | --- |
| **用的是什么** | 不透明，可能套壳/二次封装 | **官方真实订阅账号** |
| **价格逻辑** | 运营方赚差价 | **多人平摊，明码标价** |
| **人数** | 从不告诉你背后挤了多少人 | **几人拼写清楚，不偷塞人** |
| **立场** | 你和卖家是买卖关系 | **大家都是拼车的用户，组局透明** |

## 为什么拼车更划算

官方订阅（比如 Claude、ChatGPT Pro）单人原价不便宜，但一个人往往用不满额度。拼车把闲置的额度利用起来：

- **3 人拼**：人少，每人能分到的并发和额度更宽裕，响应更从容 → 价格更高
- **4 人拼**：人多，单价更低，适合日常轻中度使用 → 性价比更高

你按自己的使用强度选车型，不用为用不完的额度买单。

## 怎么开始

1. 登录 [控制台](https://api.pingcodes.cc) 注册账号、选拼车套餐
2. 在控制台 **API Keys** 页创建你的专属 Key
3. 用 [CC-Switch](./cc-switch-install) 或 [Codex++](./codex-plus-plus-install) 把 Key 配进你的 AI 客户端
