# 什么是 PingCodes 拼车

PingCodes 是一个 **AI 订阅拼车平台**——把 Claude、OpenAI、Gemini 等官方 AI 订阅，按 **3 人、4 人** 的方式拼着用，价格大家平摊。

简单说：**一个官方真号的钱，几个人分着出，每人只花一小部分。**

## 拼车，而不是中转

市面上很多服务叫"中转站"——本质是二道贩子转发请求，你不知道背后是不是套壳、数据会不会被留存。PingCodes 走的是**拼车**模式：

| | 普通中转站 | PingCodes 拼车 |
| --- | --- | --- |
| **用的是什么** | 不透明，可能套壳/二次封装 | **官方真实订阅账号** |
| **价格逻辑** | 运营方赚差价 | **多人平摊，明码标价** |
| **人数** | 从不告诉你背后挤了多少人 | **几人拼写清楚，不偷塞人** |
| **立场** | 你和卖家是买卖关系 | **大家都是拼车的用户，组局透明** |

## 为什么拼车更划算

官方订阅（比如 Claude、ChatGPT Pro）单人原价不便宜，但一个人往往用不满额度。拼车把闲置的额度利用起来：

- **3 人拼**：人少，每人能分到的并发和额度更宽裕，响应更从容 → 价格更高
- **4 人拼**：人多，单价更低，适合日常轻中度使用 → 性价比更高

你按自己的使用强度选车型，不用为用不完的额度买单。

## 拼车最怕两件事，我们都解决了

拼官方订阅，最让人担心的就两点：**号会不会被封**、**额度会不会被别人占光**。PingCodes 在这两点上都做了硬机制，不是靠承诺。

### 🛡️ 统一出口 IP，保号防封

每个拼车号都绑定一个**固定的专属出口 IP**。不管车上的人分布在哪、用什么网络，请求到官方时**都从同一个稳定 IP 出去**——在官方眼里始终是"同一个人在正常使用"，极大降低触发风控、被封号的概率。

这正是"正规车队"和"杂牌中转"的区别：杂牌中转任由一堆人的 IP 乱撞同一个号，封号是迟早的事；我们一车一 IP，稳。

### ⚖️ 额度按人分配，不互相挤

每个拼车位都有**独立的并发额度**，彼此隔离。不会出现"一个人疯狂跑任务把整车额度吃光，其他人全卡死"的情况——你买的那一份，**有保障地留给你**。

### 🤝 明算账，不超卖

标几人拼，后台就只放几个人，**绝不偷偷塞人**。这是我们和大多数中转最本质的区别。

## 想和朋友自己组一车？

如果你有认识的人想一起开车，我们支持**熟人组队**——你拉上自己的朋友 / 同事组成一个专属车队，额度只在你们几个之间分，不和陌生人拼。

适合：小团队内部共享、和信得过的朋友 AA。需要组队直接联系我们就行。
